# Chatty-2.0

## Описание проекта
Проект посвящен развитию функциональности веб-приложения **Chatty 2.0** для преподавателей и учеников, изучающих английский язык. 

Основная цель аналитического этапа — разработка и расширение спецификации требований к ПО для двух ключевых пользовательских модулей: **интерактивных карточек для запоминания слов** и **встроенного видеоплеера для просмотра контекстного употребления лексики в речи**.

---

## Роль и выполненные задачи

В рамках проекта мной были реализованы следующие задачи:

### 1. Проектирование модуля карточек для запоминания слов:
- Разработка функциональных требований к созданию, удалению карточек и тренажеру проверки знаний.
- Составление табличных вариантов использования (Use Cases).

### 2. Спецификация функции просмотра видеоконтента:
- **UML-моделирование:** интеграция сценария просмотра видеопримеров в общую диаграмму Use Case.
- **Табличный Use Case:** составление сценария с предусловиями, постусловиями, базовым сценарием и 8 альтернативными ветками (пауза, перемотка во время воспроизведения/паузы, полноэкранный режим, отсутствие видеофайла).
- **Функциональные требования:**составление требований к видеоплееру и всем элементам управления воспроизведением.

### 3. Работа с разделами спецификации:
- **Атрибуты качества:** формулирование критериев юзабилити, производительности (задержка старта до 3 сек, отклик плеера до 1 сек), безопасности лицензионного контента и доступности.
- **Интеграционные требования:** описание взаимодействия с внешней библиотекой видеофайлов.
- **Бизнес-правила:** описание правил проверки авторских прав.
- **Глоссарий:** добавлены определения для новых терминов видеоплеера.

## Выводы и результаты

- **Проработка логики:** написала сценарии использования (Use Cases) и требования, благодаря чему поведение системы стало прозрачным и понятным для каждого шага пользователя.
- **Добавление новых функций:** карточки слов и видеоплеер органично дополнили существующий словарь, не нарушив привычную работу приложения.
- **Требования к видеоплееру:** описала все сценарии работы видео — от перемотки и паузы до полноэкранного режима и возможных ошибок.
- **Защита от рисков:** отобразила правила соблюдения авторских прав и требования к качеству видео при разной скорости интернета, чтобы сервис работал стабильно.
